01 — O que chamamos de IA

O que chamamos de IA

Inteligência Artificial reúne técnicas para resolver tarefas como reconhecer padrões, planejar e tomar decisões. Parte dessas técnicas usa regras explícitas; outra parte aprende relações a partir de dados. Aprendizado de máquina, ou machine learning, é esse segundo conjunto.

Em robótica, a pergunta prática é: qual informação falta para decidir o próximo movimento? Detectar um objeto em uma imagem pode exigir um modelo aprendido. Manter a velocidade de uma roda pode ser resolvido por um controlador convencional. A escolha começa pelo problema e por uma forma de medir o resultado.

Objetivo do guia

Distinguir IA, machine learning e deep learning; organizar um experimento; e entender por que testar com dados novos é tão importante quanto treinar.

02 — Escolha a ferramenta para a tarefa

Escolha a ferramenta para a tarefa

AbordagemComo funcionaExemplo didático
Regras e buscaUsa conhecimento e procedimentos definidos no projeto.Planejar uma rota em um mapa conhecido.
Machine learningAjusta parâmetros usando dados para prever ou classificar.Classificar leituras de um sensor.
Deep learningUsa redes neurais com várias camadas; é um subcampo de machine learning.Reconhecer objetos em imagens.
Controle clássicoCalcula ações a partir de modelos e erros de referência.Regular velocidade com PID.

Essas abordagens podem trabalhar juntas. Um detector fornece a posição estimada de um alvo; uma lógica de decisão escolhe a ação; um controlador comanda o movimento. Um PID não precisa aprender com dados para funcionar.

Uma regra simples, como comparar um sensor com um limiar, também é uma boa referência inicial. Só adicione um modelo quando houver um ganho mensurável em relação a essa solução.

03 — Do dado à avaliação

Do dado à avaliação

1
Defina a tarefa
Exemplo: classificar uma leitura como superfície clara ou escura. Escolha antes do treino o que conta como acerto e quais erros são mais importantes.
2
Colete e identifique
Registre a leitura, a classe correta e as condições: iluminação, distância e sessão de coleta. Corrija rótulos inconsistentes.
3
Separe os conjuntos
Use treino para ajustar, validação para escolher configurações e teste para a avaliação final. Amostras quase idênticas da mesma sessão podem exigir separação por sessão.
4
Treine e compare
Comece com uma referência simples. Compare configurações usando validação, sem consultar o teste para escolher o modelo.
5
Avalie e use
Avalie uma vez no conjunto reservado, analise os tipos de erro e meça o tempo de inferência no equipamento final.
Evite vazamento de dados

A normalização também aprende parâmetros. Ajuste-a apenas com o conjunto de treino. Se informações do teste influenciam o treinamento ou a escolha do modelo, o resultado deixa de representar uma avaliação independente.

Veja os exemplos sobre vazamento de dados e pipelines na documentação do scikit-learn.

04 — Experimento sem biblioteca de IA

Experimento sem biblioteca de IA

O exemplo usa um classificador de centroide mais próximo: ele calcula a média de cada classe e atribui uma leitura ao centro mais próximo. Os números abaixo são sintéticos; não representam medições da equipe nem comprovam desempenho em um sensor real.

Python 3classificador_sensor.py
# Dados sintéticos: (leitura, classe).
treino = [(120, "escura"), (160, "escura"), (200, "escura"),
          (720, "clara"), (780, "clara"), (820, "clara")]
teste = [(180, "escura"), (740, "clara"), (500, "escura")]

classes = sorted({classe for _, classe in treino})
centros = {}
for classe in classes:
    valores = [valor for valor, rotulo in treino if rotulo == classe]
    centros[classe] = sum(valores) / len(valores)

def prever(valor):
    return min(centros, key=lambda classe: abs(valor - centros[classe]))

acertos = 0
for valor, esperado in teste:
    previsto = prever(valor)
    acertos += previsto == esperado
    print(valor, "esperado:", esperado, "previsto:", previsto)

print(f"Acertos: {acertos}/{len(teste)}")

Salve e execute com python classificador_sensor.py. O resultado esperado é 2 acertos em 3 exemplos. A leitura 500 é classificada como clara, embora o rótulo do teste seja escura. O erro mostra a limitação dessa separação simples.

O código só usa o treino para calcular centros; o teste mede o resultado. Para continuar, colete dados reais em condições diferentes, separe sessões e compare com um limiar fixo. Três exemplos são insuficientes para estimar a qualidade de um sistema real.

05 — Integre a percepção à decisão

Integre a percepção à decisão

Em um projeto de robótica, o modelo deve entregar algo que o restante do sistema consiga interpretar: classe, posição ou outra estimativa bem definida. Especifique unidades, validade temporal e o que fazer se uma leitura faltar.

Pergunta de projetoO que registrar
O modelo melhora a referência simples?Mesma tarefa, mesmos dados de teste e uma métrica comparável.
Cabe no equipamento?Memória, tempo por amostra e consumo, medidos no hardware escolhido.
Funciona em outro ambiente?Resultados por iluminação, distância, câmera ou sessão.
O que acontece quando falha?Critério para rejeitar a previsão ou interromper a ação.

O treinamento pode ocorrer em um computador e a inferência em outra placa. Isso depende do modelo: um Uno R3 tem recursos muito diferentes dos de um computador embarcado. Não presuma que todo modelo roda em qualquer Arduino.

06 — Glossário essencial

Glossário essencial

TermoSignificado
DatasetConjunto de dados organizado para uma tarefa.
RótuloResposta de referência associada a uma amostra.
TreinamentoAjuste dos parâmetros do modelo.
InferênciaUso do modelo ajustado para produzir uma previsão.
OverfittingBom desempenho no treino sem generalizar adequadamente para dados novos.
Matriz de confusãoContagem dos acertos e erros separada pelas classes reais e previstas.

A acurácia total pode esconder um problema: se quase todos os exemplos forem de uma classe, sempre prever essa classe pode parecer bom. Examine os erros de cada classe antes de decidir se o modelo atende à tarefa.

07 — Próximos passos

Próximos passos

Você tem um caminho completo: definir, coletar, separar, treinar e avaliar. O próximo exercício é escrever uma ficha curta com tarefa, origem dos dados, referência simples, métricas e limitações antes de escolher uma rede neural.

Para trabalhar com imagens, siga o guia de visão computacional. Ele começa com segmentação por cor, uma técnica que permite experimentar percepção sem treinar um modelo.
